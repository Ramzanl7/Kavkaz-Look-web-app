# Курьеры в Kavkaz Look

## Как работает сейчас (без подключения служб)
1. Покупатель оформляет заказ с доставкой. Стоимость доставки берётся из настроек бутика и сохраняется в заказе.
2. Продавец принимает заказ → **«Вызвать курьера»** → выбирает службу из списка (его ведёт админ).
3. Приложение готовит текст заявки: откуда забрать, куда везти, телефон покупателя, сколько взять с покупателя
   (товары + доставка). Продавец отправляет его в WhatsApp/Telegram службы или звонит.
4. Покупатель получает уведомление «Курьер вызван». Продавец отмечает: «Курьер назначен» → «Забрал» → «Доставлен».
5. «Доставлен» закрывает заказ. Если доставка не удалась — продавец получает уведомление и может вызвать курьера снова.
6. Автопилот (каждые 15 минут): напоминает продавцу вызвать курьера через 2 часа после принятия заказа,
   сообщает админам о заказах, не отправленных за сутки, и о вызовах без назначенного курьера за 3 часа.

## Подключение службы доставки (для партнёра)
Когда служба согласна работать с Kavkaz Look:
1. Админ добавляет службу в «Службы доставки» и нажимает **«Выдать ключ»** — ключ показывается один раз.
2. Служба получает заявки (как сейчас, в WhatsApp/Telegram, с номером доставки `delivery_id`) и сообщает статусы
   на наш адрес — тогда продавцу ничего отмечать не нужно.

### Адрес и формат
```
POST https://<проект>.supabase.co/functions/v1/delivery-webhook
Authorization: Bearer <ключ службы>
Content-Type: application/json

{
  "delivery_id": "8c1f…",           // номер доставки из заявки (или "external_id" — ваш номер, если вы его прислали раньше)
  "status": "assigned",             // assigned — курьер назначен, picked_up — забрал, delivered — доставил,
                                    // failed — не удалось доставить, cancelled — отменено
  "courier_name": "Ислам",          // необязательно
  "courier_phone": "+79281234567",  // необязательно
  "tracking_url": "https://…",      // необязательно: ссылка, где покупатель видит курьера
  "note": "Покупатель не отвечает", // необязательно: причина для failed/cancelled
  "set_external_id": "ORD-1234"     // необязательно: ваш номер заказа, чтобы дальше слать статусы по нему
}
```
Ответы: `200 {"ok":true}`; `401` — неверный ключ; `404` — доставка не найдена; `400` — неверный статус.
Статусы можно присылать повторно — лишний раз ничего не сломается; назад по цепочке статус не откатывается.
