# Kavkaz Look на российской площадке (Amvera)

Зачем: сайты на Vercel из России работают нестабильно, особенно с мобильного интернета.
Здесь приложение раздаётся с сервера в России, а запросы к базе Supabase идут через этот же сервер
(адрес `/sb`) — телефону не нужно напрямую обращаться к иностранным серверам.

## Что внутри
- `Dockerfile` — собирает приложение и запускает nginx + маленький сервер превью ссылок.
- `deploy/nginx.conf` — раздача приложения, кэш, заголовки безопасности, «прокладка» `/sb/` → Supabase, превью для WhatsApp/Telegram.
- `amvera.yml` — настройки для Amvera (сборка по Dockerfile, порт 80).

Vercel продолжает работать как раньше — это запасной адрес.

## Подключение (один раз)
1. Зарегистрируйтесь на amvera.ru → «Создать проект» → тип «Приложение».
2. Источник кода — **GitHub**, репозиторий `Kavkaz-Look-web-app`, ветка `main`.
3. Конфигурация возьмётся из `amvera.yml` автоматически (Docker, порт 80). Переменные окружения задавать не нужно.
4. Дождитесь сборки (несколько минут) и откройте выданный адрес вида `….amvera.io` — должен открыться Kavkaz Look.
5. Домен: купите на reg.ru (например, `kavkazlook.ru`) → в Amvera «Домены» → добавить домен →
   в reg.ru пропишите DNS-запись, которую покажет Amvera → дождитесь выпуска сертификата.
6. В Supabase → Authentication → URL Configuration добавьте новый адрес в Site URL / Redirect URLs
   (нужно для писем сброса пароля).

Дальше всё автоматически: слили PR в `main` → Amvera пересобирает и обновляет сайт.
