# Kavkaz Look — контекст проекта для новой сессии (Claude Code)

## Кто и что
Рамзан, 20 лет, Грозный, делает один, с помощью ИИ. Новичок: объяснять пошагово, по-русски.
Правила работы: ничего не делать без его разрешения (но предлагать идеи); только правда, без лести;
не врать и не подстраиваться. Сообщения часто голосом — слова бывают искажены.

**Kavkaz Look** — веб/PWA маркетплейс одежды для Грозного/Чечни (не App Store/Google Play).
Роли: buyer, seller, admin. Один тёмный стиль: тёмно-зелёный #061914 + золото #D6B56A, чеченский орнамент,
плавная анимация. Только русский язык.

## Жёсткие условия
- Не использовать чужие фото/видео/шрифты без лицензии; законы РФ и традиции Чечни; без мок-данных
  (пустые состояния вместо выдуманных товаров); реальные фото — позже, от друга, с письменным согласием.
- Безопасность: RLS на всех таблицах, цена заказа считается на сервере, ввод санитизируется,
  секреты не в репозитории и не в чате. Ключ в src/lib/supabase.js — только publishable (публичный по дизайну).
- 152-ФЗ: Supabase сейчас зарубежный (Франкфурт) — это dev. До реальных пользователей перенести на
  российский сервер (self-hosted Supabase). До этого не хранить телефоны/адреса/мерки.
- Мультфильмные векторные рисунки отклонены.

## Стек
React 19 + Vite 8 + react-router-dom 7, PWA, @fontsource (Noto Sans, Noto Serif Display, self-hosted),
@supabase/supabase-js 2, pngjs (иконка "K" генерируется при сборке: scripts/make-icons.mjs).
Версии закреплены точно. Сборка: `npm run build`.

## Что сделано
Каталог (поиск, сортировка, чипы, скелетоны), товар, корзина и заказ через RPC (тестовый режим),
бутики, избранное, отзывы и рейтинги, заказы покупателя (отмена), кабинет продавца
(товары с фото+миниатюрой, заказы), заявки на роль/партнёра, админ-панель, «Сделано рядом»,
нижняя навигация (Каталог, Бутики, Избранное, Корзина, Профиль), кнопка «назад», анимации переходов.
Структура: src/pages, src/components, src/api/index.js (слой данных), src/auth, src/store, src/design (CSS).
